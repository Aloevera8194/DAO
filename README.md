# DAO

Acelerador de downloads para Android: cola o link de um site ou pasta, o app lista os arquivos por tipo (com subpastas) e baixa só o que for marcado.

## Recursos

- **Pasta de destino:** pasta padrão do celular, uma pasta escolhida por você, ou um servidor na rede (Raspberry Pi via SFTP). Configurações no botão ⚙.
- **Pausar e continuar:** por arquivo ou "Pausar tudo / Continuar tudo". A lista de downloads é salva em disco: ao fechar e abrir o app, tudo volta como pausado e continua de onde parou (quando o servidor aceita retomada).
- **Arquivo já existe:** perguntar, ignorar, manter os dois ou substituir.
